==================================================
Vinyl Hunter OS — Cloudflare Worker 部署指引
==================================================
全部操作在 cloudflare-worker 目录下完成。
已为你准备好 deploy.bat 脚本，双击或命令行运行即可。

--------------------------------------------------
前提条件
--------------------------------------------------
1. 有 Cloudflare 账号（免费注册：https://dash.cloudflare.com/sign-up）
2. 有 DeepSeek API Key（https://platform.deepseek.com/ → API Keys → 创建）
3. DeepSeek 账户里充了至少 ¥1（够分析几百次）

--------------------------------------------------
第一步：登录 Cloudflare（只需一次）
--------------------------------------------------
打开命令行（CMD 或 PowerShell），进入 cloudflare-worker 目录：

  cd C:\Users\25121\WorkBuddy\2026-08-10-16-41-28\cloudflare-worker

运行：

  deploy.bat login

浏览器会自动打开 Cloudflare 授权页面，点击"Allow"即可。
登录成功后命令行会显示 "Successfully logged in"。

--------------------------------------------------
第二步：设置 DeepSeek API Key（只需一次）
--------------------------------------------------

  deploy.bat secret

命令行会提示你输入 Key，粘贴你的 DeepSeek API Key（sk-开头），按回车。
Key 会加密存储在 Cloudflare，不会出现在任何代码文件里。
设置成功后显示 "Success! Uploaded secret DEEPSEEK_API_KEY"。

--------------------------------------------------
第三步：部署到云端
--------------------------------------------------

  deploy.bat deploy

部署成功后，命令行会显示你的 Worker 地址，类似：

  https://vinyl-proxy.<你的子域>.workers.dev

把这个地址记下来！

--------------------------------------------------
第四步：在工作台里配置
--------------------------------------------------
打开 Vinyl Hunter OS → 系统设置，填入：

  中国热搜代理地址：https://vinyl-proxy.<你的子域>.workers.dev
  AI分析代理地址：  https://vinyl-proxy.<你的子域>.workers.dev/ai-analyze

保存后，11 个模块的 AI 分析按钮就能调用真实 DeepSeek 分析了。

--------------------------------------------------
验证是否成功
--------------------------------------------------
浏览器直接访问你的 Worker 地址：
  https://vinyl-proxy.<你的子域>.workers.dev

如果返回类似 {"words":["..."],"updatedAt":1234567890} 的 JSON，
说明热搜代理正常工作。

--------------------------------------------------
可选：本地测试（不部署到云端）
--------------------------------------------------

  deploy.bat dev

启动后访问 http://localhost:8787 测试。
注意：本地测试时需要创建 .dev.vars 文件来存放 Key：
  DEEPSEEK_API_KEY=sk-你的key
（此文件已在 .gitignore 中，不会上传 GitHub）

--------------------------------------------------
后续更新
--------------------------------------------------
如果修改了 china-hot-proxy.js，重新部署只需：

  deploy.bat deploy

几秒钟就更新完成。

--------------------------------------------------

--------------------------------------------------

DeepSeek API：约 ¥0.003-0.005/次分析
每天 50 次分析 ≈ ¥0.25/天，月 ¥7-8
